# Code of Conduct

Vehkernel adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in every project space: issues, pull requests, reviews and any other channel the project uses, and when someone represents the project in public.

In short: be respectful and constructive, assume good faith, critique work and not people, and accept that maintainers decide what is merged. Harassment, personal attacks and publishing others' private information are not tolerated.

## Reporting

Report conduct problems privately to the maintainers, never in a public issue:

- Open a private report from the repository's [Security tab](https://github.com/chimu0510/Vehkernel/security/advisories/new) and start its title with `Code of conduct:`. Only the maintainers can see it.
- For content that breaks GitHub's own rules, also use GitHub's [Report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature.

Maintainers will review every report, keep the reporter's identity confidential, and respond following the Contributor Covenant's enforcement guidelines: correction, warning, temporary ban or permanent ban.
