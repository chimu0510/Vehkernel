# AHRS Bench（姿態估測工作台）

與 `examples/demos/ahrs_bench` 韌體互動的 Web UI，用來理解並調整控制板上的姿態估測（`ekf_ahrs` 乘性誤差 EKF 與 `ahrs` Mahony）。
不接控制板也能用：內建有真值的模擬器。

```bash
tools/c50c.py flash ahrs_bench
```

```bash
tools/ahrs_bench/server.py
```

開啟 http://localhost:8008 。不接控制板時：

```bash
tools/ahrs_bench/server.py --sim drive
```

需要 Python 3、pyserial、numpy、scipy 與 gcc（`tools/setup.sh` 會檢查）。網頁的圖表、3D 與公式函式庫（uPlot、three.js、KaTeX）從 jsDelivr 載入，第一次開啟需要網路。

## 原理

- **同一份 C 代碼**：伺服器啟動時以 gcc 把 `examples/common/ekf_ahrs.c`、`ahrs.c` 編成主機的共用函式庫（`native.py`，輸出在 `.build/`），濾波器副本與控制板執行的是同一份代碼。
- **A（目前）**：接控制板時，參數與重設時機都跟控制板相同，逐筆重現韌體的計算。控制板只送原始量測與輸出；共變異數、創新量、卡爾曼增益這些內部量來自副本。頂端「副本與韌體最大差」顯示兩者的差距，差異只來自浮點運算順序（控制板的編譯器會用 FMA），應遠小於 0.01°。
- **B（候選）**：只在主機上執行的第二組參數，與 A 吃同一份資料，用來比較；按「B → A 套用」才會寫入控制板（不存 Flash，重新開機恢復預設）。
- **真實雜訊模型**：與濾波器參數分開，供模擬器產生資料、供分析計算「實際 σ」。濾波器參數是濾波器以為的雜訊，兩者不同就是模型不符。

## 分頁

| 分頁 | 內容 |
|---|---|
| 即時監看 | 3D 姿態（A、Mahony、B、真值）、數值面板、角度、1σ、零偏、原始讀值、NIS、自適應 σ、與真值的誤差（模擬）、副本與韌體的差 |
| 模型檢視 | EKF 每一步的公式與即時數值：狀態、預測、量測模型、增益與修正、ZUPT、Mahony 與 EKF 的關係、可觀測性。本體座標的 3D 場景畫出 v、â、創新量 y、S 與 HPHᵀ、P<sub>θθ</sub> 橢球、EKF 的 δθ 與 Mahony 的 K<sub>p</sub>eΔt；P 的相關係數與 K 的熱圖 |
| 參數分析 | 參數表（點名稱看說明）；單軸線性化分析：穩態摘要（濾波器自認 vs 實際 σ、等效 K<sub>p</sub>/K<sub>i</sub>、頻寬）、σ 來源分解、互補濾波頻率響應、誤差頻譜、加速度與零偏的時域響應、增益取捨、|a| 自適應、yaw 誤差成長 |
| 離線模擬 | 有真值的模擬情境（靜止、傾斜、加減速、原地旋轉、行駛），A、B 兩組參數一次跑完：誤差與 ±2σ、零偏估計、NIS、統計 |

每張圖的說明預設收起，按標題右側的 ⓘ 展開，或勾選頂端的「顯示所有說明」。

線性化分析假設小角度、角速度約 0、|a| ≈ 1 g，用的是 EKF 的穩態增益；非線性、自適應 σ、拒絕門檻與靜止偵測的效果要看離線模擬（同一份 C 代碼在模擬資料上執行）。

## 錄製與重播

「● 錄製」把收到的原始量測存到 `recordings/<時間>.npz`（不提交到 git），之後可以從頂端選「重播錄製檔」，用不同參數重跑同一段資料。

## 協議

USART1 改為 921600 baud 的二進位協議（COBS 分幀、CRC16），定義在 `examples/demos/ahrs_bench/bench_proto.h` 與 `protocol.py`，兩邊要一起改。這是本工具專用的簡化協議，不是 ADR-0003 的控制板與 Raspberry Pi 5 協議。韌體執行時一般串口終端機看到的是亂碼。
