# English is the project language

Everything in the repository and its tracker is written in English: README, glossary, ADRs, agent docs, code and comments, diagnostics, commit messages, issues and pull requests. The early design docs were written in Traditional Chinese and have been translated, so that contributors, tools and upstream projects such as ArduPilot and PX4 share one vocabulary. The English terms in GLOSSARY.md are canonical.

## Consequences

- New text follows the tone of ArduPilot and PX4 documentation: short, technical, active voice.
- Translated READMEs may be added later as separate files (for example `README.zh-TW.md`). The English README stays the source of truth, and translations only mirror it.
- Third-party vendor material kept outside version control is exempt.
