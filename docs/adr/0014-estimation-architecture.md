# 估測分成可替換的估測器模組與數學元件函式庫

MCU 端只做局部估測（ADR 0001），範圍如下：

- IMU 處理：讀 FIFO、校正、依板級定義旋轉安裝方向、濾波。
- 姿態估測。
- 輪式里程計：航向用陀螺儀積分，不用左右輪速差。

輸出同時包含校正後的原始資料與融合結果，都帶共變異數。不使用 ICM20948 的 DMP，因為它是封閉的晶片內韌體，時序與濾波都不透明，也拿不到共變異數。磁力計依 Frame 選用。

**第一層：估測器模組**

- 每個估測器是一個獨立的工作項目，發布標準的狀態 Topic（如 `vehicle_attitude`、`vehicle_local_odometry`），並帶估測器 ID。控制鏈只訂閱標準 Topic。
- 用參數選擇主要估測器。可以同時執行多個估測器：被選中的發布到標準 Topic，其他的發布到診斷 Topic，用來比較演算法，主要估測器不健康時也能切換到備援。

**第二層：數學元件函式庫**

依數學模型切割，放在 `lib/estimation/` 下：

- 過程模型，例如四元數運動學、輪式運動學。
- 量測模型，例如加速度計、磁力計、輪速、深度計。
- 濾波演算法，例如互補濾波、EKF、ESKF。
- 不配置記憶體的數學工具。

估測器 = 一個演算法 + 若干模型的組合。函式庫完全不依賴匯流排與 HAL，可以在主機上用錄下的資料做單元測試與資料回放。

開發初期只實作「互補濾波（Mahony）+ 四元數運動學 + 加速度計模型」，但目錄與介面一開始就照這個結構建立；EKF 等演算法之後再加入。
