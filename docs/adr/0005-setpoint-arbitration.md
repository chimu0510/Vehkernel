# Setpoint 仲裁：模式決定控制權，遙控器可隨時接管

同一時間可能有多個來源送 setpoint（上位機、遙控器、地面站）。我們不採用固定的來源優先序，而是由目前的模式決定哪個來源有控制權，概念同 PX4 的 offboard 模式。例如在上位機模式下，只接受 Bridge 送來的 setpoint。

另外有兩條規則不受模式限制：

- **遙控器隨時可以接管或急停。** 這是獨立運作與安全的最後防線。
- **有控制權的來源逾時，載具會退到該 Frame 設定的安全行為。** 例如地面載具停車，水下載具懸停或上浮。

## Considered Options

- **固定優先序（遙控器 > 地面站 > 上位機）**：不採用。上位機正在自主運行時，低優先級來源的狀態會被高優先級來源隨意打斷，而且無法清楚表達「現在是誰在開」。
