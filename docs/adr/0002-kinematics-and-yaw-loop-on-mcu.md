# 運動學與 ωz 閉環放在 C50C 控制板，介面只交換車體速度

借鑑 ArduPilot GUIDED／PX4 offboard 的分工：C50C 控制板負責所有高頻、硬即時與安全相關的控制，並且在沒有 Raspberry Pi 5 的情況下也能完整遙控行駛；Raspberry Pi 5 只負責需要地圖或大量運算的工作（位姿積分與 EKF、SLAM、Nav2）。因此差速運動學、左右輪速 PID，以及以 ICM-20948 陀螺儀做的 ωz 閉環都在控制板上；兩者之間只交換車體速度 (Vx, ωz)，不交換各輪速度。ωz 閉環用來補償兩顆馬達的特性差異，讓遙控與自主模式都能走直、轉準。

## Consequences

- 遙控與自主模式共用同一份運動學，不存在兩份實作對不上的問題。
- 控制板回報量測的車體速度、左右輪速與 IMU 原始資料（皆帶時間戳）；位姿積分、`odom` 與座標轉換只在 ROS2 端。
- 底盤是差速而非滑移轉向，輪式里程計的轉向角速度可信，EKF 可同時採用輪式與 IMU 的轉向角速度。
- 有效輪距與輪徑需實測標定；原廠韌體輪徑 0.254 m 與 URDF 量測 0.208 m 不一致，兩者都不可直接採信。

## Considered Options

- **只做運動學、ωz 開環（原廠做法）**：否決，走直線要靠左右輪補償係數，無法隨負載與地面變化修正。
- **運動學放在 Raspberry Pi 5（ros2_control `diff_drive_controller`）**：否決，遙控行駛時控制板仍需自己一份運動學，兩份容易脫節，且 Raspberry Pi 5 離線就無法遙控。
