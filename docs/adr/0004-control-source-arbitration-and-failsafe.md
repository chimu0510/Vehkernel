# 控制來源固定優先序 SBUS > USB 手柄 > Raspberry Pi 5，失效保護以減速斜坡停車

C50C 控制板同時處理 SBUS 與 USB 手柄兩個遙控來源，加上 Raspberry Pi 5 共三個控制來源。採固定優先序 SBUS > USB 手柄 > Raspberry Pi 5：較高優先的來源一有輸入就接管，只有它主動釋放（例如 SBUS 撥回自主模式檔位、手柄按下釋放鍵）後，較低優先的來源才能取回控制權。這讓測試自主算法時任何時候都能用遙控器把車搶回手動，且兩個人同時操作也不會互搶。

任一控制中的來源逾時或失聯（Raspberry Pi 5 心跳逾時、SBUS failsafe 旗標、USB 手柄斷線）或電量過低時，進入失效保護：依設定的最大減速度把車體速度降到 0 後鎖住馬達，而不是立即歸零。這避免充氣輪打滑甩尾、感測器支架受衝擊，全向輪端在前時也較穩。

## Considered Options

- **SBUS 三段開關當總選擇器**：否決，未接 SBUS 接收機時需要另外定義預設行為。
- **最後有輸入者優先**：否決，多人操作時會互搶，測試自主算法時不安全。
- **立即停車**：否決，高速時可能打滑或晃動。
- **依來源分開處理失效保護**：否決，規則較多、需要更完整的測試；必要時可在此基礎上再細分。

## Consequences

- 無論處於哪個模式，控制板都持續回報車體速度與 IMU，所以遙控建圖與自主導航對 Raspberry Pi 5 是同一條資料流。
- 最大減速度是需要依實車調整的參數。
