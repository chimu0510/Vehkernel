# C50C 控制板與 Raspberry Pi 5 之間使用自訂串口協議

兩者經 CH9102F USB 轉串口連接，使用自訂二進位協議：COBS 分幀、CRC16 校驗、訊息 ID 加序號、控制板微秒時間戳、連線時交換協議版本，訊息由同一份定義產生 C 與 C++ 兩端的程式碼。時間戳是為了讓 Raspberry Pi 5 估算時鐘偏移，把里程計與 IMU 對齊到光達所用的 ROS 時間；版本交換與 ADR-0001 的車頭方向比對都在連線握手時完成。

## Considered Options

- **擴充原廠協議**：否決。固定長度幀頭 `0x7B` 可能出現在資料中造成失同步、BCC（XOR）校驗太弱，且沒有時間戳、序號、版本與狀態欄位。
- **micro-ROS**：否決。韌體會依賴 ROS 的 agent 與 DDS 記憶體模型，違反控制板獨立運行的原則（ADR-0002），除錯也較困難。
- **MAVLink 自訂 dialect**：程式碼產生器與工具成熟，但對單台車而言偏重，且訊息需遵守 MAVLink 規範；若日後需要地面站生態再重新評估。

## Consequences

- 協議定義是兩端唯一的共用介面，應帶版本號並獨立於韌體與 ROS2 程式碼存放。
- CAN（VP230）不用於此通訊，保留給日後擴充。
